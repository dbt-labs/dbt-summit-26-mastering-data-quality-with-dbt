# dbt skills

Repo-local dbt skills available to agents working in this project:

| Skill | Use it for |
| --- | --- |
| `adding-dbt-unit-test` | Unit tests with mocked dbt inputs and expected outputs |
| `building-dbt-semantic-layer` | Semantic models, entities, dimensions, metrics, and time spines |
| `running-dbt-commands` | Safe dbt command selection, selectors, and flags |
| `troubleshooting-dbt-job-errors` | Investigation of dbt platform job failures |
| `using-dbt-for-analytics-engineering` | Models, sources, macros, tests, snapshots, and validation |
| `migrating-dbt-core-to-v2` | dbt Core to dbt v2 Stable migration triage |

Each skill lives at `<skill-name>/SKILL.md` and is source-controlled with this project.
